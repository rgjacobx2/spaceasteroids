# Space Asteroids

There isn't a direct executable. So you will have to download the gamemaker tool from Yoyo Games at https://gamemaker.io/

1. Download Gamemaker from https://gamemaker.io/
2. Import this project
3. Run game


It's my first attempt at making a game, so hardly a no brainer on the control scheme.

# You will have to shoot down 5 asteroids to win.

Controls:
1. Right and left buttons for direction change
2. Up button for acceleration
3. Space button to fire.
